Runtime settings

Configure host, port and logging through config.yaml.

The server manager loads config.yaml from the current location or near the executable, which makes the generated deploy bundle self-contained.

Common settings

server:
  address: "127.0.0.1"
  port: 8008
logging:
  enabled: true
  level: "info"
  to_file: true
  file_path: "logs/app.log"

Command-line overrides

./@PROJECT_NAME@ --log --log-level debug
./@PROJECT_NAME@ --log-file logs/debug.log

Keep production config beside the deployed binary.
