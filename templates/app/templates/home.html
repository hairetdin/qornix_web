1. Add routes

Edit routes.h, register a handler and rebuild. The default app starts with /, /health and documentation routes.

2. Create handlers

Place handlers under handlers/. Derive from HandlerBase and override methods such as handleGet or handlePost.

3. Deploy the bundle

After build, copy build/deploy/@PROJECT_NAME@ to another directory or compatible machine and run the binary from that folder.

Useful files

  • routes.h - central route registration
  • handlers/health_handler.h - minimal JSON handler example
  • templates/*.html - UI pages served by the app
  • static/app.css - shared UI styles
  • config.yaml - server address, port and logging settings

Need a database-backed API?

The default template is intentionally small. To start with Schema Manager, Dynamic API, Query Builder and Table Browser, generate a dynamic API application instead:
