First run

Your generated application is ready.

The default template gives you a clean starting point for a custom C++ web app. It does not assume a database or a dynamic API; you add only the features you need.

Build

mkdir -p build
cd build
cmake ..
cmake --build .

Run

cd build/deploy/@PROJECT_NAME@
./@PROJECT_NAME@

Then open http://127.0.0.1:8008/.

Project layout

  • main.cpp starts the server.
  • routes.h registers routes.
  • handlers/ contains request handlers.
  • templates/ contains HTML pages.
  • static/ contains CSS and assets.

First useful edit

Add a new handler under handlers/, include it in routes.h, register a path, rebuild and refresh the page.

When to use Dynamic API

Use --with-dynamic-api when you want Schema Manager, query builder, table browser and schema-driven CRUD API out of the box.
