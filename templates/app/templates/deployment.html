Portable bundle

Run the app from another directory or compatible machine.

The build creates a deploy directory containing the binary and runtime assets. Copy that whole folder, not only the executable.

Build deploy bundle

mkdir -p build
cd build
cmake ..
cmake --build .

# Bundle location:
build/deploy/@PROJECT_NAME@/

Run from bundle

cd build/deploy/@PROJECT_NAME@
./@PROJECT_NAME@

Or set QORNIX_APP_ROOT explicitly when running from another location.

Bundle layout

@PROJECT_NAME@/
├── @PROJECT_NAME@
├── config.yaml
├── README.md
├── templates/
├── static/
├── doc/
├── route_extensions/
└── logs/

The bundle does not include system shared libraries. On another machine, install compatible runtime dependencies or use your normal package/container workflow.

Runtime image

docker build -f runtime-Dockerfile -t @PROJECT_NAME@:runtime .
docker run --rm -p 8008:8008 @PROJECT_NAME@:runtime

Container runtime

The Dockerfile copies build/deploy/@PROJECT_NAME@/ into /app, sets QORNIX_APP_ROOT=/app and makes the server listen on 0.0.0.0 inside the container.
