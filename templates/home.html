🦅 Qornix Web Server

QORNIX - Query Object Routing Network Integration eXperience

Welcome to an extensible C++ web server. This server uses an architecture that makes it easy to add new functionality.

The server is built on Boost.Beast and supports modern web standards.

🔌 Extensibility

Add new routes and functionality through dynamically loaded extensions.

🔄 Dependency Injection

Manage dependencies through a container with support for different object lifetimes.

🧩 Middleware

Use a middleware chain for logging, authentication and other cross-cutting tasks.

⚡ Async Processing

Handle requests across multiple threads for high performance.

🧭 Available Routes:

  • / - this page
  • GET /health - Check server health
  • GET /info - Server information
  • GET /notfound - 404 page
  • /users - user management
  • /users/{id} - access a specific user
  • /api/v1/users - API for users
  • /api/v1/users/{id} - API for a specific user

🛠️ For Developers:

Create your extensions in the route_extensions/ directory.

Use BaseHandler as the base for your handlers.

Register services through DIContainer.
