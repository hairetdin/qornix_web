🎯 Описание API

Этот сервис предоставляет универсальный REST API для работы с таблицами базы данных.

📋 Доступные endpoint'ы

GET /api/dynamic

Динамический запрос с указанием таблицы в query параметрах

GET /api/dynamic/{table}

Получить все записи из таблицы с фильтрацией через query параметры

GET /api/dynamic/{table}/{id}

Получить конкретную запись по ID

POST /api/dynamic/

Создать новую запись в таблице

PATCH /api/dynamic/

Частичное обновление существующей записи

PUT /api/dynamic/

Обновить существующую запись

DELETE /api/dynamic/

Удалить запись из таблицы

GET /api/dynamic/schema.xml

Экспорт XML-схемы текущей demo SQLite базы

⚙️ Технические детали

  • Фреймворк: Qornix Web Server
  • Язык: C++17
  • База данных: PostgreSQL/MySQL/SQLite

  • Формат данных: JSON
  • Поддерживаемые операции: SELECT, INSERT, UPDATE, DELETE, JOIN
  • Защита: Автоматическая защита от SQL-инъекций
  • Интерфейс: CodeMirror JSON Editor
